- 서비스 오픈: **2026년 4월**. 방문 지표(DAU·UV·PV)는 개편 효과가 아니라 오픈 이후 성장으로 본다.
- 쇼핑탭 개편 배포 시점: **확인 필요**. "6월 말"과 "5월 말" 두 가지로 전달됨. 아래 표는 6월 말 기준.
  5월 말 기준이면 5월이 개편 전, 6월부터 개편 후: 6~9월 평균 5.86% (5월 대비 +1.27%p), 7~8월 평균 7.29% (+2.70%p).

- 8월 값: 원본 표 7.72% (이전 정리값 7.73%).

## OK캐쉬백 쇼핑탭 방문 지표 (`ocb-shopping-visits.csv`)

- 4월 오픈 이후 일평균 DAU 46,412 → 108,223 (10월, 진행 중, 약 2.3배). 9월 97,575 (+110%).
- MAU 286,833 → 515,643 (9월, +80%). PV 214만 → 1,059만 (9월, 약 4.9배).
- 5월(첫 정상 월) 기준 9월: DAU +84%, UV +28%, PV +126%, UV당 PV +77%.
- 4월은 오픈월이라 부분 월일 수 있음 (오픈일 확인 필요). 일평균 DAU는 4월 기준도 비교 가능, UV·PV는 5월 기준이 안전.
- 신규방문·WINBACK(휴면 복귀)은 4월부터 집계가 시작돼 5월 값이 인위적으로 높고 WINBACK은 0. 월별 비교에 쓰지 않음.
- 전월 재방문 인원은 9월 +39%지만 재방문율은 69% → 59%로 하락.
