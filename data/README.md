## 오락 서비스별 UV·PV (`olock-service-pv.csv`)

- 출처: BI 서비스별 UV/PV, 25년 2월~12월. 25년 6월 고도화(홈/하단 탭 개편) 배포.
- '오늘'·'MY'·'오늘,플레이'는 6월 개편으로 메뉴가 바뀌어 7월부터 거의 0 또는 집계 종료. '포인트 적립'은 4월부터 집계 안 됨.

탄소몬 잡기 vs 오늘, 걸음 PV:

| 월 | 탄소몬 잡기 | 오늘, 걸음 | 탄소몬 비중 |
|---|---|---|---|
| 25년 5월 | 5,163만 | 6,433만 | 44.5% |
| 6월 (배포) | 6,185만 | 6,627만 | 48.3% |
| 7월 | 7,082만 | 6,502만 | 52.1% ← 추월 |
| 8월 | 7,106만 | 6,371만 | 52.7% |
| 9월 | 7,233만 | 6,401만 | 53.0% |
| 12월 | 7,248만 | 6,211만 | 53.9% |

- 비중 = 탄소몬 ÷ (탄소몬 + 오늘, 걸음). 이전 정리값 "44.5% → 53.0%"는 5월 → 9월로 확인됨.
- 7월부터 12월까지 6개월 연속 탄소몬 잡기 PV가 오늘, 걸음보다 큼.
- 월 합계 기준 탄소몬 잡기 PV 5월 → 9월 +40.1%. 일평균 기준으로는 +44.8% (아래).

| "전체 PV +21.5%" | **오늘, 걸음 + 탄소몬 잡기** 합계 일평균 PV, 5월 → 9월 | +21.5% (서비스 전체 아님) |
| "전체 PV +9.7%" | 서비스 전체 일평균 PV, 5월 → 9월 | 2,988만 → 3,277만 (+9.7%) |

- 24년 리브랜딩 패널은 Power Index 기준으로 확정 (위 Power Index 섹션).
