## OK캐쉬백 쇼핑탭 구매전환율 (`ocb-shopping-conversion.csv`)

- 쇼핑탭 개편 배포: **6월 말** → 6월은 개편 전, 7월부터 개편 후로 본다.
- 원본 표의 기준월이 `2026-05~09`로 찍혀 있음. 슬라이드 기간(25년)과 맞는지 확인 필요.
- 이전 정리값은 8월 7.73%, 원본 표는 7.72%. 표 값(7.72%)으로 저장.

| 비교 | 값 | 차이 |
|---|---|---|
| 6월 (개편 전) | 3.99% | 기준 |
| 7월 | 6.86% | +2.87%p (상대 +72%) |
| 8월 (최고) | 7.72% | +3.73%p (상대 +93%) |

- 8월 구매고객수 15,955 → 34,428명 (약 2.2배, +116%), 구매금액 약 +94%.
- 7월 객단가 26,879 → 16,636원 (−38%): 소액 구매 고객이 늘어난 달. 구매금액보다 전환율·구매고객수 중심으로 말한다.
- 9월 하락: 8월 대비 −2.85%p. 이벤트·프로모션 효과가 빠졌을 가능성 확인 중. 5/20 적립→쇼핑 이벤트 영향이 5월 값에 섞였을 수 있음.

슬라이드 문구:

> 6월 말 쇼핑탭 개편 이후 구매전환율 3.99% → 6.48% (7~9월 평균, +2.49%p). 8월 최고 7.72%, 9월 4.87%로 조정되었으나 개편 전 수준을 상회.

5~6월 평균 기준으로 쓸 때는 "4.29% → 6.48% (+2.19%p)".
