- 4월 오픈 이후 일평균 DAU 46,412 → 97,575 (9월, +110%) → 108,223 (10월 진행 중, 약 2.3배).

- 전월신규고객재방문은 5월에 전월재방문과 같은 값(197,092)이라 집계 시작 효과. 6월부터 의미 있음.

## 오락 월별 트래픽 (`olock-monthly-traffic.csv`)

- Power Index와 값이 조금 다름 (예: 24년 6월 MAU 368,887 vs 371,788). 23년·25년 11~12월처럼 Power Index에 없는 달 참고용.

- 출처: 오락 내부 관리 엑셀의 '오락 월별 서비스 현황'(MAU·DAU, 23.05~25.12)과 '오락 일별 모니터링'(신규 회원수, 24.07~26.03).
- MAU·DAU는 **서비스 전체** 값. 슬라이드의 "신규 사용자 MAU", "신규 재방문률"은 이 엑셀에 없음.
- `new_users_sum_of_daily`는 일별 신규 회원수(UV)를 월별로 더한 값. 신규 MAU(월 순 신규 이용자)와 같은 지표인지 확인 필요.
- 일별 데이터가 24년 7월부터 시작해서 24년 6월(리브랜딩 전) 신규 값이 없음.
- 전체 MAU: 24년 6월 368,887 → 9월 475,783 (+29%). 9월은 단발성 피크 (10월 415,576).
- 25년 2차 개편 전후 전체 MAU: 6월 458,089 → 7월 491,678 (+7%) → 9월 443,816.
